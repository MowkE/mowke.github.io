samaOS 1.0

A small operating system that runs inside this page. Programs are written in sama, compiled to bytecode, and run on a virtual CPU. A round-robin scheduler shares that CPU between every running program, 400 instructions at a time.

Written by Samahith, in JavaScript, from scratch.
